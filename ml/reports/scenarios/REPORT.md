## Технические границы и материалы

Оставшихся технических блокеров проверенного scope не выявлено. S18 — OUT_OF_SCOPE: 20 ANAMNESIS_DRAFT-правил не включались; сведения о диабете переданы врачу, ложное назначение эндокринолога не появилось. Это не подтверждение соблюдения интервала.

Отдельное расхождение реализаций: в прочитанном main только GET /, /health, /fields; ветка engine/PR4 `c2f39680aee388365daa180329a58edfb0f4081c` содержит иной, не подключённый router. Её выбор по календарному возрасту, нули вместо неизвестного курения, маршрут после red_flags, названия вместо ID и вычисленные повторы не переносились; её тесты не считались нашими. Конфликт источника «15 лет» остаётся открытым и изолирован в review. Согласованный локальный двухэтапный контракт сохраняет приоритет.
