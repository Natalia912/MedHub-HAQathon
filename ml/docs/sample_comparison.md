# Совместимая регрессия автоматического /predict: девять примеров

Это сохранённое сравнение прежнего автоматического сценария: `POST /predict` → `prime_checkup.engine.build_plan()`. Оно повторно выполнено текущим движком, но **не описывает ответ нового `/recommend`**: первый этап нового API не ищет слоты. Двухэтапная интеграция описана в [CONTRACT.md](CONTRACT.md).

Источник: неизменённый `reference/df733c4/ml/sample_inputs.json`, SHA репозитория `df733c43d5ab655ef08036366a44bae04e59182f`. Сводка воспроизводится командой `python -m tools.compare_samples`; полные исходные `screen` и сводки фактического результата находятся в [sample_comparison.json](sample_comparison.json).

Версии движка в этом прогоне: `demo-3`. SHA выше обозначает происхождение анкеты и данных, а не текущий commit локального кода. Исходные примеры и технические даты не заменяются новым remote или текущей датой машины.

Даты расчёта: `as_of_date=2026-09-30`, `checkup_year=2026`, условный визит `2026-10-01`, слоты `normal`. В движок передаётся исходный `input` без дополнения медицинскими ответами; технические значения берутся из явно возвращённых демо-настроек. `screen` — снимок поведения прежнего интерфейса, а не медицинский эталон или результаты обследований.

Во всех девяти случаях разбор выполнен. Все результаты имеют `demo=true`, `medical_validated=false`. Термин исходного экрана `free_rules` ниже цитируется только для сравнения: новый блок не подтверждает право на бесплатное прохождение.

Готовые маршруты в этой таблице подтверждают только размещение в синтетических слотах. Предварительный состав при `review` сохраняется для обсуждения и не выдаётся за полный согласованный маршрут. Совпадения скринингов с пакетом не удаляют услуги; результаты обследований и даты персональных повторов из анкеты не создаются. Во всех девяти черновиках `due_date=null`, `sent=false`.

Таблица отражает вызовы совместимого автоматического `build_plan`, а не новый `/recommend` или старый replay-cache. Скрипт проверяет неизменность входного файла и результатов при повторном расчёте каждого примера; клиническая корректность этим не подтверждается.
