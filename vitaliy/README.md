## Что здесь
- `checkup-local/` — приложение: анкета Натальи (стиль Green Clinic) → программа PRIME + бесплатный госскрининг
  (приказ ДСМ-174/2020 в ред. № 75) → информированное согласие → подготовка с вопросами и иллюстрациями →
  экран врача-куратора (состав, подпись согласия, утверждение, итоговый лист) → карта здоровья и напоминания →
  утро клиники (карусель кабинетов по списку Анар, своё время прихода, сколько чекапов в день) → 12 пациентов.
  Подробно — `checkup-local/README.md`.
- `pitch/` — презентация (`Checkup_Intelligence_pitch.pdf`, исходник `deck.html`), тексты и речь (`CONTENT.md`),
  сценарий демо по секундам (`DEMO_SCRIPT.md`).

## Запуск
```
cd vitaliy/checkup-local
pip install -r requirements.txt
python -m uvicorn app:app --port 8010
```
http://localhost:8010 — анкета, http://localhost:8010/app — дальнейшие экраны. Проверка: `python -m pytest -q`.
