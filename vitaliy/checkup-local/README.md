# Check-up Intelligence — зелёный коридор чекапа PRIME

MedHub HAQathon, 30.09.2026 · задача 2 «Check-up Intelligence» · партнёр — Green Clinic / PRIME

## Команда
Команда Qorgan: Анар Кыстаубаева — медицинский эксперт (правила анамнеза, анкета) · Наталья Третьякова — разработчик ·
Даниил Габриэльян — ML и данные · Виталий Бош — продукт, нормативная база, питч.

## Проблема
Пациенту нужно выбрать чекап из пакетов PRIME, но он не знает, какие обследования нужны ему с учётом возраста, пола и
анамнеза, и что часть обследований положена бесплатно по госскринингу. После чекапа результаты разрознены, повторы
пропускаются.

## Решение
Цепочка **анкета → программа PRIME → информированное согласие → маршрут на один день → карта здоровья → напоминание о повторе**. Без ИИ-моделей:
все правила — таблица `spec/rules.json`, у каждой строки источник. Врач утверждает правила один раз, скрипт применяет их
к каждому пациенту. Диагноз не ставим — программу утверждает врач-куратор.

0. **Согласие на обработку ответов** — до анкеты; имя и ИИН не спрашиваем.
1. **Анкета** — простыми словами, без жалоб: что есть или было, на учёте ли, семья, курение, лекарства, женское/мужское
   здоровье, вопросы для процедур. «Беспокоит прямо сейчас» — анкета останавливается: это не чекап (103).
2. **Программа** — пакет PRIME по полным годам и полу; бесплатный скрининг по приказу МЗ РК ҚР ДСМ-174/2020 (в ред.
   приказа № 75 от 10.07.2026) по году достижения возраста; если обследование есть и там, и там — пациент выбирает:
   «бесплатно в поликлинике до 60 дней» или «в PRIME сегодня». Добавки сверх пакета — по правилам анамнеза.
3. **Информированное согласие** — по каждой процедуре программы простыми словами: что это, зачем, риски, альтернатива
   (в т.ч. бесплатный скрининг). Письменно — на бланке клиники у куратора; без отметки «подписано» куратор не может
   утвердить программу. Основание — Кодекс РК «О здоровье народа и системе здравоохранения» № 360-VI, ст. 134.
4. **Подготовка** — по дням (сейчас / накануне / утром / после), под каждым пунктом вопрос на понимание.
5. **Врач-куратор** — видит анкету и программу, убирает или добавляет услугу из каталога PRIME, утверждает, печатает
   итоговый лист.
6. **Карта здоровья** — отметки «пройдено», результаты, оценка чекапа 1–5, повторы в календарь (.ics).
7. **Маршрут дня** — по кабинетам медэксперта, у каждой процедуры блок «Как подготовиться».
8. **Утро клиники** — карусель 13 кабинетов по списку медэксперта (УЗИ 3 места с переключением на 2, ФГДС и колоноскопия
   отдельно, колоноскопия последней, УЗИ 20 мин за исследование): кто натощак — раньше, наркоз — последним, каждому своё
   время прихода (не позже 10:30 — кровь натощак). Скрипт считает, сколько полных чекапов клиника берёт в день: на модели
   8 из 11 до 18:00 при 3 местах УЗИ (6 — при 2). Если все 11 придут в 08:00 — среднее ожидание 247 мин.
9. **Демо «12 пациентов»** — все этапы для 12 синтетических пациентов, с записью по дням: день 1 — 8 человек, среднее
   ожидание 40 мин, все свободны к 17:42; день 2 — 3 человека. Пациент с «беспокоит сейчас» остановлен на анкете.

Метрики трека в продукте: продажи чекапов (добавки сверх пакета), время прохождения (карусель), повторные визиты
(напоминания), удовлетворённость (оценка в карте здоровья).

## Демо
Вкладка «12 пациентов» — все этапы сразу. Кнопки «Демо-пациенты» на первом экране заполняют анкету. Сценарий на 60 секунд:
Ж 42, на учёте по давлению, рак кишечника у отца → «Подобрать программу» → Подготовка → Куратор «Утвердить» →
Карта здоровья → Утро клиники (переключатель режимов прихода).

## Запуск
```
pip install -r requirements.txt
python -m uvicorn app:app --port 8010
```
Открыть http://localhost:8010. Проверка правил: `python -m pytest -q` (12 контрольных пациентов + карусель).

## Структура проекта
```
engine.py          движок: predict() и карусель утра — только порядок применения правил
app.py             FastAPI: страница и API (/api/predict, /api/morning, /api/samples, /api/catalog, /api/sources)
static/            экран без внешних зависимостей (HTML, JS, CSS, шрифт Geologica — OFL)
spec/rules.json    все правила с источниками: пакеты PRIME, скрининги, анамнез, подготовка, маршрут, кабинеты
spec/examples.json 12 контрольных пациентов с ожидаемым ответом
spec/sample_inputs.json  эталонные пациенты анкеты (синтетика)
spec/demo_patients.json  12 демо-пациентов сценария
normativ/          тексты приказа ДСМ-174/2020 и изменений № 75
test_engine.py     проверки
```

## Что готово
- Вся цепочка трека работает end-to-end на синтетических пациентах; 12/12 контрольных.
- Только open source, без внешних API и платных моделей (требование Green Clinic).

## Ограничения (честно)
- Правила анамнеза, подготовка к УЗИ/КТ/маммографии/ЭКГ и тексты согласий — черновик, утверждает врач клиники.
- Бланк информированного согласия — клиники; мы даём пояснение простыми словами и отметку «подписано».
- Цен пакетов на сайте PRIME нет — в программе цены не показываем.
- Кабинеты — со слов медэксперта; места, длительности, приход до 10:30 и конец дня 18:00 — допущения. Клиника вносит свои в `rules.json`, код не меняется. Все цифры карусели — модель, не замер.
- Интеграции с МИС нет: на пилоте итоговый лист печатается куратором.
